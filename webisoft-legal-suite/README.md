# Webisoft Legal Suite (WS Legal)

افزونه‌ی وردپرس برای سایت‌های **وکالتی و حقوقی** (بهینه برای Hello Elementor + Elementor)، ساخته‌شده از ادغام و بازنویسی اسنیپت‌های WPCode.

## ویژگی‌ها
- ۱۸ ماژول با شورت‌کد (هیرو، جستجو، حوزه‌ها، کارت‌های Sticky، تب «مشکل شما چیست؟»، فرآیند، تجربه‌های موفق، گواهی‌ها، FAQ + اسکیما، آمار، نظرات، تیم، CTA، درباره، تماس، فرم درخواست، آخرین مقالات، آرشیو مقالات)
- **حالت روشن/تاریک** با ذخیره انتخاب کاربر، بدون فلش سفید، سازگار با Hello Elementor
- تمام متن‌ها، آیکون‌ها، رنگ‌ها (جدا برای روشن و تاریک)، فونت، گردی گوشه‌ها و محتوای تکرارشونده از **wp-admin ← وبی‌سافت حقوقی**
- فرم‌های واقعی: ذخیره در «درخواست‌ها (Leads)»، ایمیل، honeypot، زمان‌سنج، محدودیت IP
- ابزارهای مقاله: `[reading_time]`، `[article_summary]`، `[article_actions]`، استایل محتوا، دکمه «مشاهده تمام فهرست» برای TOC المنتور
- آواتار اختصاصی، آپلود فونت، دکمه‌های تماس شناور، اسکیمای LegalService، ایمپورت/اکسپورت تنظیمات

## نصب
1. پوشه `webisoft-legal-suite` را zip کنید (یا از `dist/webisoft-legal-suite.zip` استفاده کنید).
2. وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فعال‌سازی.
3. **اسنیپت‌های قدیمی WPCode را غیرفعال کنید** (تداخل شورت‌کد/استایل).
4. منوی «وبی‌سافت حقوقی» ← اطلاعات دفتر، رنگ و فونت، حالت تاریک، و محتوای هر ماژول را تنظیم کنید.

## ساختار
```
webisoft-legal-suite/
├─ webisoft-legal-suite.php   # بوت‌استرپ
├─ includes/                  # اسکیما، گزینه‌ها، رندر، فرم‌ها، ادمین
└─ assets/{css,js}
```
همه‌ی بخش‌های ادمین به‌صورت خودکار از `includes/class-wsl-schema.php` ساخته می‌شوند؛ برای افزودن ماژول جدید کافی است یک بخش در اسکیما و یک متد `mod_<نام>` در `class-wsl-render.php` اضافه کنید.
