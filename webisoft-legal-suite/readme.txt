مجموعه ماژول‌های آماده برای سایت‌های وکالتی و حقوقی با شورت‌کد، حالت روشن/تاریک، فرم دریافت درخواست و پنل تنظیمات کامل.

== Description ==
* ۱۸ ماژول صفحه (هیرو، حوزه‌ها، FAQ، فرآیند، مقالات، فرم‌ها و ...) با شورت‌کد
* حالت روشن/تاریک با ذخیره انتخاب کاربر و سازگار با Hello Elementor
* همه متن‌ها، رنگ‌ها، فونت‌ها و آیکون‌ها از wp-admin قابل تنظیم
* ذخیره درخواست‌ها (Leads)، ایمیل اطلاع‌رسانی و ضد اسپم
* ایمپورت/اکسپورت تنظیمات برای انتقال بین سایت‌ها

== Installation ==
۱. پوشه webisoft-legal-suite را zip کنید و از افزونه‌ها ← افزودن ← بارگذاری نصب کنید.
۲. افزونه را فعال و از منوی «وبی‌سافت حقوقی» تنظیم کنید.
۳. اسنیپت‌های قدیمی WPCode را غیرفعال کنید.
