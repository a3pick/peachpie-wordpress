# Webisoft Video Showcase 2.0 — پلی‌لیست مجزا برای هر صفحه

- ویرایش هر صفحه/پست/CPT → باکس «ویدیوهای این صفحه» (شناسه و شورت‌کد همان‌جا نمایش داده می‌شود).
- ویجت المنتور (منبع: خودکار / همین پست / پلی‌لیست / ID دلخواه-داینامیک / سراسری) یا شورت‌کد:
  - `[wvs_showcase]` → ویدیوهای پست/صفحه‌ی جاری (داخل لیستینگ جت‌انجین = هر آیتم)
  - `[wvs_showcase id="123"]` → ویدیوهای پست یا پلی‌لیست 123
  - `[wvs_showcase source="global"]` → لیست سراسری قدیمی
- منوی «ویترین ویدیویی › پلی‌لیست‌ها»: پلی‌لیست مستقل برای استفاده در چند صفحه.
- سازگاری: ویجت‌های قبلی (حالت خودکار) اگر صفحه ویدیو نداشته باشد، همان لیست سراسری قبلی را نشان می‌دهند.
